# AGENTS.md — Крипты Санкр-Тор (веб-прототип)

## Стек и цель
- Web: Vite + TypeScript + Phaser 3. Desktop (позже): Electron для сохранения данных разработчика.
- Нарративная сцена E1–E10 содержательно связана с PSS-10 по меткам `pss_item` (1–10) и типам реакций `D/C/G` (логируются скрыто).
- Стандартизированный опросник PSS-10 в веб-прототипе предъявляется **в режиме с тестированием дважды — до и после игры**, в классической форме вне сюжета. В режиме без тестирования не предъявляется. Режим выбирается игроком в `ModeSelectScene`.
- Результаты и логи хранятся локально (`localStorage` в браузере; позже — файлы на ПК разработчика в .exe). В сеть ничего не отправляется.

## Правила
- Не хардкодить игровые тексты/баланс/события — использовать JSON в `public/data` или `src/data`.
- Любое изменение логики PSS — с юнит-тестами (`vitest`).
- Не добавлять аналитику, телеметрию, отправку данных PSS/логов на сеть.
- Не показывать игроку метки `D/C/G`, `pss_item` как диагностику и не делать диагностических выводов.
- Результаты PSS показывать только по явному запросу игрока, нейтрально.
- Сохранять авторский стиль текста (см. `CRYPTS_SANCR_TOR_WEB_PROJECT.md` и материалы в `design/source/`).
- Перед коммитом: `npm test` и `npm run build` (когда применимо).
- Секреты/ключи API не коммитить (`.env`, ключи в окружении).
