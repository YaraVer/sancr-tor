# Графика: что и куда класть

Этот файл — краткая инструкция по папке `public/assets`. Полная спецификация — в `CRYPTS_SANCR_TOR_WEB_PROJECT.md` (раздел 8).

## Базовые параметры проекта
- Логическое разрешение игры: **640×360**, целочисленный масштаб, `pixelArt: true`.
- Базовый тайл: **32×32 px**.
- Спрайты персонажей: **32×32** (на карте/в бою), 8 направлений (N, NE, E, SE, S, SW, W, NW).
- Портреты для диалогов: **отдельные изображения 96×96** (или 64×64), это НЕ те же 32×32 спрайты.
- Формат: PNG, RGBA, прозрачный фон, без сглаживания и полупрозрачных ореолов по краям.
- Имена файлов: только строчные латинские буквы, цифры и дефис.

## Минимум для первого играбельного среза
1. `celestina` + `tan` + `hirdmen-shieldwall` — уже подключены.
2. Один тайлсет зоны I (подступы/врата): пол, стены, снег/грязь, вода.
3. Портрет Селестины 96×96 и портрет Зерекса 96×96.
4. Простые FX: свечение меча, пар, иней.

## Чего сейчас не хватает у сгенерированных спрайтов
- Только состояние **Idle** (8 поворотов), нет ходьбы/атаки/получения урона.
- Нет портретов для диалогов.
- Групповой спрайт `hirdmen-shieldwall` — это четверо гномов в одном кадре; для отдельных юнитов нужны индивидуальные спрайты.

## Как добавить новый спрайт-пак
Автоматически (рекомендуется):
```powershell
# прямо из zip-архива генератора
npm run sprites:import -- --zip "C:\Users\USER\Downloads\my_pack.zip" --id zereks --name "Зерекс" --role "Некромант"

# или из уже распакованной папки
npm run sprites:import -- --dir "C:\path\to\extracted" --id zereks --name "Зерекс"

# проверить все спрайты (наличие 8 направлений и размер 32×32)
npm run sprites:check
```
Скрипт сам скопирует 8 PNG в `public/assets/characters/<id>/idle/`, проверит размер и добавит/обновит запись в `public/data/characters.json`.

Вручную:
1. Сгенерировать/экспортировать 8 PNG по 32×32 с прозрачным фоном.
2. Положить в `public/assets/characters/<id>/idle/` с именами направлений из списка выше.
3. Добавить запись в `public/data/characters.json`.
4. Перезапустить `npm run dev`. Проверить: титул → «Проверка спрайтов» (или открыть `http://localhost:5173/?scene=SpritePreviewScene`).

## Правила стиля
- Единая палитра и освещение: тёплое золото Света Селестины против сизого холода крипт.
- Контур читаемый на тёмном фоне; без «мыла» и лишних полутонов.
- Не смешивать разные масштабы пикселя в одном кадре.
