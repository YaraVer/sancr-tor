## Приоритет 2 — анимации для Селестины и Тана
Для каждого направления (или хотя бы для S/SE/E/NE/N) добавить:
- `walk` — 4 кадра;
- `attack` — 3–4 кадра;
- `hit` — 1–2 кадра;
- `cast` — 3 кадра (Селестина, Бронн, Пирокар, Зерекс).

Формат: `public/assets/characters/<id>/walk/<direction>/01.png` … `04.png`. После появления анимаций обновить `public/data/characters.json` (добавить state) и `PreloadScene` загрузит их автоматически.

## Приоритет 3 — портреты для диалогов
Портреты — **отдельная генерация**, не апскейл 32×32:
- размер: **96×96** (допустимо 64×64), PNG RGBA;
- погрудный портрет, нейтральное выражение + 1–2 эмоции;
- палитра и освещение как у спрайтов;
- путь: `public/assets/portraits/<id>.png`.

Минимум: `celestina.png`, `zereks.png`, `tan.png`, `brunn.png`, `lars.png`.

## Где генерировать: рекомендуемый стек

Судя по `metadata.json` (`group_id`, `states`, `template_id: "mannequin"`, `directions: 8`, `export_version: 3.1`), текущие спрайты — экспорт **PixelLab**. Для анимаций логичнее продолжить там же, чтобы сохранить identity персонажа. Остальные категории лучше делать в pixel-native инструментах, а не в обычных «нейросетях для картинок».

| Категория | Где генерировать | Чем дорабатывать | Почему |
|---|---|---|---|
| Спрайты, 8 направлений | **PixelLab** (тот же character pipeline) | Aseprite / LibreSprite | Сохраняет лицо, палитру и пропорции между состояниями |
| Анимации walk / attack / hit / cast | **PixelLab** (анимация персонажа) или **Retro Diffusion → Advanced Animations** по одному кадру idle | Aseprite: тайминг, очистка, выравнивание по пиксельной сетке | PixelLab лучше держит 8 направлений; Retro Diffusion удобен для одиночных действий и FX |
| Портреты 96×96 | **Retro Diffusion** (RD Core/RD Pro, стиль Character/UI, true pixel grid) | Aseprite: глаза, контур, эмоции | Портрет нельзя качественно получить апскейлом 32×32; нужен отдельный рендер |
| Тайлсеты 32×32 | **Retro Diffusion → Tilesets** (seamless X/Y) или **PixelLab tileset** | Aseprite + **Tiled** | Нужны бесшовные тайлы и сборка карты, а не одна картинка |
| UI (рамки, плашки, иконки) | **Aseprite вручную** (AI — только как референс) | Aseprite | UI требует точных размеров, 9-slice и читаемости; AI часто даёт «мыло» |
| FX (свечение, пар, иней, оковы) | **Aseprite** покадрово; либо Retro Diffusion Custom Action по одному кадру | Aseprite + Phaser particles | Короткие циклы 6–12 кадров проще нарисовать/дочистить вручную |
| Палитра | **Lospec** (готовые палитры) | Aseprite | Единая палитра на все зоны и UI |
| Карта и коллизии | **Tiled** (бесплатно) | экспорт JSON → Phaser | Стандартный формат тайлмапов для Phaser |

### Практическая схема
1. **PixelLab** — все 8-направленные спрайты и базовые анимации.
2. **Retro Diffusion** — портреты, тайлсеты, UI-панели, отдельные FX; полезная функция **My Styles**: обучить стиль на 3–5 текущих спрайтах, чтобы новые ассеты были в той же палитре.
3. **Aseprite / LibreSprite** — обязательная доработка: убрать полупрозрачные ореолы, выровнять по сетке, сделать тайминг анимаций, дорисовать лица/эмоции.
4. **Tiled** — сборка карт и экспорт в Phaser.
5. **Lospec** — палитра, **не** генерировать цвета «на глаз».

### Ориентиры по бюджету (проверять актуальные тарифы)
- Retro Diffusion: от $5 на баланс, примерно $0.05–0.18 за изображение; новые аккаунты часто дают небольшой бесплатный баланс.
- PixelLab: тариф зависит от плана; для 8-направленных персонажей это основная статья расходов.
- Aseprite — разовая покупка (около $20), LibreSprite — бесплатно.
- Tiled и Lospec — бесплатно.

### Чего избегать
- Апскейл 32×32 → 96×96 «нейросетью»: получится мыло, а не портрет.
- Генерация UI и текста в обычных AI-картиночных сервисах: нечитаемые буквы и несовпадение пиксельной сетки.
- Смешивание 8-направленных спрайтов из разных генераторов без общей палитры: персонажи перестают выглядеть одним отрядом.
- Прозрачные PNG с полупрозрачными краями: на тёмном фоне появится ореол.

## Технические требования
- 32×32 для персонажей; 96×96 для портретов; 32×32 тайлы.
- Прозрачный фон (alpha 0), без полупрозрачного ореола.
- Один размер пикселя; без размытия и градиентов.
- Имена файлов: строчная латиница, цифры, дефис.
- Проверка: `npm run sprites:check` и сцена «Проверка спрайтов».
